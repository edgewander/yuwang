# 比斯普里镜头下的意大利监狱

![9.65.1](./images/9.65.1.webp)



![9.65.2](./images/9.65.2.webp)


![9.65.3](./images/9.65.3.webp)



![9.65.4](./images/9.65.4.webp)

耗时十年在南美洲拍摄了 74 座监狱之后，意大利摄影师比斯普里(Valerio Bispuri)把镜头转回意大利，走访了15所该国的监狱，2019年出版了摄影集《囚犯》。

![9.65.5](./images/9.65.5.webp)



![9.65.6](./images/9.65.6.webp)

意大利有190所监狱，与很多国家的监狱一样，存在着过度拥挤、设备老化落后、管理人员不足等问题。
