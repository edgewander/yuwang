# “我喜欢没有自由的感觉”  一则未完成的访谈

上上篇推送发出后，我在后台看到一条留言：“你也喜欢监狱吗？”有点疑惑，回：这个公号做了8年，应该算吧。对方：“能加个微信吗？我也是喜欢监狱的。”我发了我的微信号。加过来的微信名叫***，微信号里面有个单词：inmate（服刑人）。中午好，刚看有人在群里发的你的公众号。我看了下，我感觉我们有点类似。哈哈喜欢监狱生活？不算吧...哦......我喜欢的是触犯法律后身份改变带来的各种歧视和困境，以及监狱看守所那些特殊的生活环境和制度。我喜欢监狱很多年了，但一直没找到同类，大多数人只是把这爱好当成某种性癖，而不是真的喜欢身份改变。我就是觉得世界上不应该就我一个。你是有过经历，然后喜欢上了？不是，我是喜欢上才去经历。进去多久？11年，03--11年。不痛苦吗？失去自由不痛苦吗？失去自由并不痛苦我喜欢没有自由的感觉。你多大了？87年。上海人吗？嗯有工作吗？有，生活还是要过的，父母我也要照顾。结婚了吗？结了。抱歉，我问这么多。没事，我也希望能找到互相理解可以说话的人，我这个想法并不是能交流的。有这种心理，不是什么错。不给你带来痛苦就挺好。不不不，有这种心理不是错，但我犯罪了就是错了。我选择做了错的事，这点不会改变。那时候你高中刚毕业？不是，我初中被我折腾到留级，03年我职校一年级。你设计并实施了一次犯罪是吗？设计不至于，就是完成了一次犯罪。现在这个情结淡化了吗？没有，出来后我拘留过几次，但没有再进监狱。你觉得这个刑期轻了还是重了？并不重，但也不轻，不重是因为我犯罪给别人带来的痛苦，不轻是因为真的进监狱后巨大的劳动量让我后悔害怕了。有一种得偿所愿的感觉吗？哈哈是的，我喜欢监狱高墙铁网的环境。但很快就有其他的感觉，后悔、害怕之类的。真进去了，真的身份改变了，很多事情还是和预料的不一样。也有享受？还是完全不，叶公好龙？对半开吧，享受和后悔害怕都有，不是完全的享受。这段经历没有改变你的这种心理？没有....喜欢就是喜欢，并没有改变，依旧向往监狱生活。甚至我不介意人家知道我有前科，我会享受人家知道我有前科后的歧视。犯罪后被处理，以及罪犯身份本身就能给我提供快乐。
那段时间我在外地，没顾上多聊。约了回头录一期播客，后来我们约到昨天中午，昨天上午我问他：中午时间能确定吗？抱歉，这周有点麻烦，三中全会维稳，我被安排了很多附加的事。司法所那边。我做一休一的，现在休息天也要报到。司法所的这种约束是不是你还挺享受？至少不烦。应该说...很喜欢。喜欢的点是？被区别对待，被强制管理。你父母会这么对待你吗？不会，但有所防备。她们更信任我妻子。这种防备会让你有点暗爽吗？然后刺激你让他们更防备做点什么或者表现的不乖。不会，伤害她们太多了。你觉得是什么让你有了这种特质？生来就有？还是一些生活经历？原因不知道，但起点是初中开年级大会，看到在台上读检查领处分的学生，就很兴奋。就是说你从小的生活环境也普通，不是比如父母老吵架，对你有什么不好的之类的？没有。你有没有尝试抑制或转移这种心理？有......（大概意思是，很难）。你被关过禁闭吗？关过。什么感觉？痛苦，非常痛苦。这点来说，跟大部分人是一样的。关了多少天？好几次，最多一次我不记得了一个多月，最少3天。过后也没有被惩罚的快感，还是说跟大部分人一样就是再也不想经历了？有惩罚的快乐，在里面关紧闭也要开大会通告的，我喜欢那个感觉。你更多喜欢不是被关本身，而是被通告，得跟社会、跟其他人有关系。关本身也喜欢。你觉得你过的还好吗这些年？不错、普通或者不开心。普通吧。
