# 八十年代的监狱生活-李百军作品


![9.45.1](./images/9.45.1.jpg)

八十年代的监狱生活


![9.45.2](./images/9.45.2.jpg)

八十年代中期，上级司法部门为了宣传监狱改造犯人方面的成就，要出版一本《再生之地》的摄影画册，因当时监狱没有专业摄影的人，就叫我去给他们拍，几个月时间，前后去了几次。
我被指定到某监狱去拍摄监狱的生活，刚去的时候，监狱的负责同志叫我穿上警服去给他们拍照，以便于身份识别和给犯人以警示作用，被我谢绝了。因为我知道这样肯定会和他们之间拉开距离，不利于拍摄，我就穿了和他们一样颜色的衣服进去了。

![9.45.3](./images/9.45.3.jpg)

监狱分生活区和工作区，那时的监狱设施还很简陋，都是平房，男女监室分别隔开管理。监室里是上下两层的双人床，被子和脸盆毛巾等整理的井井有条，女监似乎更干净一些。
工作区有几个大车间，对外称为生建机械厂，负责制造消防车。和其他工厂一样，他们也是每天八小时工作制，中间也休息几次。在这里，他们熟练地操作着各种机械设备，也有师傅带着徒弟。他们除了带着监狱管理的胸牌以外，其他和工厂的工人别无二致。

![9.45.4](./images/9.45.4.jpg)

中午时分，他们就下班吃饭，饭是白面馒头和猪肉炖白菜，还有一大缸汤随便喝，生活还是不错的。午饭后休息一小时，下午进入集体学习时间。学习当下的政策法规和时事政治，他们都听得很认真。有些学习好的，还介绍自己学习体会和改造思想的状况。晚饭后各自活动，晚上九点钟，就熄灯就寝了。
我当时给他们拍的彩色照片，连底片都上交了。这些黑白照片，是我在拍摄间隙，用巴尔达小傻瓜随手拍的几张。

李百军

1955年出生于山东沂蒙山区农村家庭，从七十年代开始摄影。曾在法国、西班牙和意大利等地办过摄影展，也出版发行过几本书。
