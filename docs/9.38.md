# 监狱摄影  意大利摄影师比斯普里作品

![9.38.1](./images/9.38.1.webp)



![9.38.2](./images/9.38.2.webp)

意大利摄影师比斯普里(Valerio Bispuri)，耗时十年在南美洲拍摄了 74 座不同的监狱。完成他雄心勃勃的名为“Encerrados”（监禁）的项目。

![9.38.3](./images/9.38.3.webp)



![9.38.4](./images/9.38.4.webp)

比斯普里曾在世界各地工作，但其他地方都比不上他在南美洲度过的时间长。该项目结合了摄影、人类学和新闻学，他试图通过监狱来了解南美大陆，他认为监狱代表了一个国家残酷而隐秘的现实。

![9.38.5](./images/9.38.5.webp)



![9.38.6](./images/9.38.6.webp)

他在他的艺术家阐述中所说：

![9.38.7](./images/9.38.7.webp)



![9.38.8](./images/9.38.8.webp)

“监狱是社会的反映，是一个国家正在发生的事情的镜子，从小型戏剧到巨大的社会和经济危机 ...我选择探索监狱的深处，与其说是谴责经常处于生存极限的情况，不如说是讲述今天仍然团结和分裂南美洲的东西。”

![9.38.9](./images/9.38.9.webp)



![9.38.10](./images/9.38.10.webp)

他的照片不仅描绘了我们视为罪犯的个人的生活，还描绘了普遍的人类真理，例如不平等、苦难和生存。

![9.38.11](./images/9.38.11.webp)



![9.38.12](./images/9.38.12.webp)

在里约热内卢一座戒备森严的监狱的女性病房里，一名妇女摆出凶猛的弗拉门戈舞姿，将杂乱无章的 18 人牢房变成了舞厅舞台。比斯普里设法在牢房的黑暗缝隙中捕捉到自然的聚光灯。

![9.38.13](./images/9.38.13.webp)



![9.38.14](./images/9.38.14.webp)

在监狱里，光是一种珍贵、稀有的东西。在所有的墙壁、路障、临时门和晾干的衣服中，比斯普里捕捉到光作为一种将内在生命与外在分开的力量，这种元素甚至可以穿透和照亮最黑暗的牢房。
