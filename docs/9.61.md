# 监狱摄影  着便服的女犯们

监狱摄影 | 着便服的女犯们

![9.61.3](./images/9.61.3.jpg)



![9.61.4](./images/9.61.4.jpg)

1977年，杰克·吕德斯·布斯（Jack Lueders-Booth）和他18岁的女儿劳拉·布斯（Laura Booth）去马萨诸塞州矫正中心（成立于1850年代）为那里的女犯们教授摄影课程，监狱管理人员给了他一个空置的监舍作为暗房，宝丽来赞助了十几台相机和不少胶卷。

![9.61.5](./images/9.61.5.jpg)



![9.61.6](./images/9.61.6.jpg)

第二年夏天，课程结束时，吕德斯-布斯觉得有必要把课程继续下去。于是，他又呆了七年。

![9.61.7](./images/9.61.7.jpg)



![9.61.8](./images/9.61.8.jpg)

课程之余，他拍了不少照片，也做了不少访谈。

![9.61.9](./images/9.61.9.jpg)



![9.61.10](./images/9.61.10.jpg)

“七年多来，这些女性持续吸引我不断来到监狱——体味她们深深的伤悲，看她们葆守自己的价值，尤其是，她们在看似不可能的糟糕状况下不放弃希望，保持乐观，为此，我非常钦佩她们。在这部作品中，我从未打算描述监狱本身（尽管有些照片不可避免地会这样），相反，我从一开始就只对女性本身、她们的家人和朋友感兴趣。”

![9.61.11](./images/9.61.11.jpg)



![9.61.12](./images/9.61.12.jpg)

随着进入次数的增加，我与警卫、典狱长和整个行政部门都越开越熟悉，他们都不介意我带着相机自顾自的随处拍摄。—— 杰克·吕德斯·布斯
