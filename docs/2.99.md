# 上海犯人在治淮等水利工程中

作者徐家俊

淮河，发源于河南桐柏山，全长1000公里，流域面积达21万平方公里，多年来水患不断。1951年春，毛主席发出了“一定要把淮河修好”的号召。中央成立了治淮委员会（简称淮委），曾山任主任，淮河流域的河南、安徽、江苏、山东四个省的省委书记分别任副主任。吴觉、张祚荫任正、副秘书长，日常工作由秘书长协调。各地先后有300万民工和数万名水利工程技术人员参加治淮。同年6月，由华东公安部牵头，成立了治淮工程总队，彭光福任司令员，解放后的首任提篮桥监狱典狱长武仲奇（后改名武中奇）调任副司令员兼参谋长。治淮总队人数最多时有5万多犯人，6个支队。一个支队下设5个大队，一个大队下设5个中队。一个中队约200名左右，一个大队约1000人，一个支队约5000人左右。治淮总队6个支队中，第一、第二支队全是上海调去的犯人，干部也是上海抽调配备的。上海从公安、劳改部门抽调了相当多的干部，在三五天内，打起行装，开赴淮北大地，扎根安徽，一干就是几十年。当时提篮桥监狱抽调的除典狱长外，还有管教科科长盛稼夫、秘书科科长宁模和孙家富等。

治淮总队的总部最初设在泗洪县九王庄。1952年7月以来，总部设在嘉山县泊岗镇，犯人增加到5万人。1954年7月以后，泊岗工程结束，总部迁设到蚌埠市。1956年华东公安部撤销，治淮总队归划淮委领导，到1958年下半年淮委撤销并入安徽省建筑厅，后又转属安徽省水利厅领导。在1962年左右，划归安徽省公安厅领导，又成立了劳改工程总队。泗洪、盱眙两县在洪泽湖周围，最初均属安徽省。因为在治淮中，涉及淮河、洪泽湖的开发利用、蓄水和排洪，淮河下游和洪泽湖周围几个县涉及各自的利害关系，工作中存在一定的矛盾，而且涉及两个省，协调起来比较麻烦，所以盱眙、泗洪县分别在1954年、1955年从安徽省划归江苏省。1954年，原属于江苏省的砀山县和萧县划归安徽省。

上海从1959～1964年先后向安徽调了七八万犯人参加治淮工程和其他水利工程。治淮工程总队的第一个任务，是位于泗洪县下草湾引河工程，即把淮河干流截弯取直，流入洪泽湖，工程全长8公里，要挖300米宽，7～8米深的人工河道；1952年下半年，又搞了泊岗引河工程。这些工程土方量很大，当时基本上都是靠人挑肩扛来完成。20世纪50年代初期，大部分犯人从上海通过火车押解到淮北临淮关下车，转乘木船，顺淮河东行到泗洪县的下草湾，再步行一段路才到治淮工程。50年代末，上海另有一批犯人是乘轮船过芜湖，从华阳一带走水路。治淮工程和其他工程中，大量需要的是一般的劳动力即沙土工，主要是挖土、挑土，用小车推土；此外，还有少量的技术工种，如木工、机械维修、钢筋工、混凝土工等。

当时干部及犯人的生活条件比较艰苦，大家都住在工棚里。工棚很简陋，用高粱秆、芦苇当墙，外糊泥土，用毛竹当梁柱起支架作用，睡的是地铺。工棚是“人”字形的，或马鞍形的。大家用的都是煤油灯，遇到下雨下雪，工棚里更为艰苦。外面下大雨，屋内下小雨，外面雨停了，屋内仍有水珠掉落下来。犯人住房周围有部队警戒。犯人穿灰色囚服，衣服不用纽扣，用带子系的。在犯人改造和生产中，也开展各种教育、评比活动。立功，分一、二、三等奖。表现突出可以获减刑。犯人刑满后，家住农村的回原籍；家在上海、南京等大城市的，留队就业。

以上海调犯组成的第一、第二支队参加的工程还有花凉亭水库，它位于大别山南麓，下距太湖县城5公里，是一座具有防洪、灌溉、发电综合性能的大型水库，很多技术犯人是上海、南京来的。此外，1955年，以上海调犯组成的第一支队由水利部调到青岛月子口水库，一直干到1958年，该水库主要是供青岛市用水。犯人还去过辽宁省抚顺附近修过大伙房水库和清河水库，相传那里是当年薛仁贵征东的地方。该地方并非历史小说中描写得如此浪漫，而是十分艰苦。这两个水库工程浩大，任务艰巨，主体工程必须抢在汛前完工。各支队进入工地后，干部带领犯人在零下40多度的气温下艰苦劳动。以后犯人又参加了安徽梅山水库、佛子岭水库、裕溪口闸、巢湖闸，还搞过长江干流的治理，参加过长江南岸的马鞍山大堤、长江北岸的无为大堤的加固工程。据统计，上海从1951年起共向各地调犯16万多人（其中包括一部分技术犯），足迹几乎涉及全国各省份。以人数来讲，调往安徽省（上海市所属的白茅岭、军天湖农场除外）约占一半左右。此外，上海在1954年还向河南调犯2000多人，在豫南参加治淮。1958年、1959年时，花凉亭水库也调过一批犯人。该处近长江边上，犯人从上海乘船从长江航道押解到安徽。当时仅有一台小发电机供工地照明用，干部、犯人住的地方均用煤油灯。治淮和其他水利工程中，也有少数犯人因病死亡，干部也有死亡的。

那时，犯人参加治淮和其他水利工程，干部也组织犯人开展一定的文娱活动。1952年组织过一个几十个犯人组成的京剧团，演出京剧“白蛇传”等。这些有一定文艺专长的犯人，以“技术犯”的名义从上海、南京调来的。当时有个女犯叫张亚斌（或张亚彬），原是个女特务，京剧票友，京剧唱得很好，在治淮工地有一定知名度。犯人刑释大多数留厂就业。分布在省水利厅、建筑厅、机械厅、农垦厅、公安厅等所属的各单位。

1959年，合肥的江淮汽车厂和肥河汽车厂基本上都是由上海、南京来的犯人或刑释留厂人员组成的，技术力量较强，形成一定规模后，划归省机械厅。还有巢湖铸造厂，原是治淮总队第一支队的底子。修完青岛月子口水库后，一部分人到巢湖闸工程，一部分人员去了巢湖铸造厂。

【注】选自《上海监狱的前世今生》，作者徐家俊。原载《上海警苑》2000年第10期、《监狱工作研究》2001年第3期。
