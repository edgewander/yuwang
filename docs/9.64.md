# 摄影师镜头下的黎巴嫩监狱

![9.64.1](./images/9.64.1.webp)



![9.64.2](./images/9.64.2.webp)


![9.64.3](./images/9.64.3.webp)

2009-2011年间，摄影师海桑·穆萨维（Haitham Moussawi）走访了黎巴嫩24所监狱，记录了该国监狱的一些日常。

![9.64.5](./images/9.64.5.webp)



![9.64.6](./images/9.64.6.webp)

几十年来，黎巴嫩监狱系统的基础设施一直饱受诟病。在该国29所监狱中，只有两所（鲁米耶监狱和扎勒监狱）一开始是按照监狱来设计建造的。其他的，有的最初用作警察局、仓库，有的位于军营的地下室，有的是安全部队的办公场所和中心内部；甚至还有可以追溯到奥斯曼时代的破旧监狱（Serail）。绝大多数牢房缺乏适当的通风和光照，更不用说供暖和空调了。

![9.64.7](./images/9.64.7.webp)



![9.64.8](./images/9.64.8.webp)

这些功能不全的监狱又因过度拥挤而更加糟糕。该国最臭名昭著的鲁米耶监狱，目前关押了约4000名囚犯，几乎是其设计容量1050人的四倍。污水和垃圾处理在困扰黎巴嫩监狱的无数问题中尤为突出。由于饮用水以及洗澡和洗衣用水的严重短缺，卫生条件持续面临危险。

![9.64.9](./images/9.64.9.webp)



![9.64.10](./images/9.64.10.webp)

穆萨维的照片也揭示了其他威胁人权的问题，比如膳食不足、医疗服务和心理健康治疗不足、缺乏床上用品，以及缺乏教育活动和体育锻炼机会。在为期三年的项目结束时，穆萨维得出了一个总体结论：“黎巴嫩的监狱比囚犯更糟糕。”
