# 查尔斯·布朗森的漫画

![8.52.1](./images/8.52.1.png)



![8.52.2](./images/8.52.2.jpg)

查尔斯·布朗森的漫画

![8.52.3](./images/8.52.3.jpg)



![8.52.4](./images/8.52.4.jpg)

查尔斯·布朗森（Charles Bronson 1952.12.6—— ），现名查尔斯·萨尔瓦多（Charles Salvador），应该是英国监狱系统中最知名的躁狂暴力犯。自1974年因持械抢劫被判入狱以来，易燃易爆炸的布朗森就一路闪电带火花，不断出状况，导致一再加刑。中间只短暂的过了69天的自由人生活，累计服刑超过50年，其中大部分时间在高度戒备的隔离监禁中度过。他曾在精神病院（如布罗德莫尔、兰普顿和阿什沃斯）接受治疗，医生曾认为他可能患有反社会人格障碍、偏执型人格障碍、精神分裂症、心理变态。也有心理学家指出监狱里的“残酷和不可接受的待遇”，也进一步加剧了他的情绪不稳定。他的监狱生涯，伴随着无数次的袭击其他囚犯和狱警，还有11次劫持人质事件，9次爬上监狱屋顶抗议，换过20多所监狱。

![8.52.5](./images/8.52.5.png)



![8.52.6](./images/8.52.6.jpg)

但一言不合就开干的布朗森，后来发展出一些安静的爱好：画漫画、写诗、写文章。把情绪宣泄到纸上，如此，他先后出版了11本书，得过十多项科斯特勒监狱艺术奖（Koestler Awards）。还拍卖作品做慈善。

![8.52.7](./images/8.52.7.jpg)



![8.52.8](./images/8.52.8.jpg)

布朗森的艺术创作始于1994年，那时候他已经在监狱生活20年了。闯了无数祸，换了十几所监狱，1994年，他再一次被送到韦克菲尔德监狱（Wakefield Prison）时，头疼的狱方把他关进以前关押连环杀人狂罗伯特·莫兹利（Robert Maudsley）所用的“汉尼拔牢笼”（Hannibal Cage）里。在这里，狱警米克·奥哈根和艾伦·贾维斯建议布朗森画画，希望通过画画帮助他平息躁动的情绪。我想象这两位的表情，“您玩玩这个？”没想到，这一建议开启了布朗森的艺术之路，他的狂躁不断在方寸纸张上迸发出想象力。布朗森喜欢超现实主义大师萨尔瓦多·达利，以至于他于2014年改名为查尔斯·萨尔瓦多，向偶像致敬。

![8.52.9](./images/8.52.9.jpg)



![8.52.10](./images/8.52.10.jpg)

布朗森的绘画带有强烈的个人印记，融合了卡通化的夸张表现和阴郁的心理暗示。他的作品题材源于他在监狱和精神病院的经历，例如反复出现的监控摄像头、牢房、精神病院、飞翔的注射器以及破碎的蛋壳（或许暗喻脆弱与重生的矛盾）。

![8.52.11](./images/8.52.11.jpg)



![8.52.12](./images/8.52.12.jpg)

布朗森的作品因其特殊身份而备受关注，曾获英国囚犯艺术盛会“科斯特勒奖”多次肯定，在多个展览中展出，并拍出数百至数千英镑的价格。他拿出部分收益捐给慈善机构，如儿童临终关怀和心理健康组织等。他也曾卖画为母亲筹集数千英镑度假资金。

![8.52.13](./images/8.52.13.jpg)



![8.52.14](./images/8.52.14.jpg)

布朗森表示艺术拯救了他，帮助他平息了内心的暴力倾向。他在监狱里还结了两次婚，一次是2001年与一名孟加拉裔离婚女子，她看到报纸上关于布朗森的报道后开始与他通信。后二人在伍德希尔监狱（HMP Woodhill）结婚，期间布朗森短暂皈依了伊斯兰教，并改名为查尔斯·阿里·艾哈迈德。四年后两人离婚，布朗森放弃了伊斯兰教。第二次是2017年，与一名女演员，她于2016年开始探视布朗森，他在电话里唱《My Way》向她求婚。婚礼在韦克菲尔德监狱举行，2018年布朗森提出离婚，2019年离婚，同年，女方因药物过量去世。

![8.52.15](./images/8.52.15.jpg)



![8.52.16](./images/8.52.16.jpg)

布朗森和他的支持者认为，他近十年没有发生暴力行为，已经改过自新了。2023年，71岁的布朗森展出并出售了一批画作，他希望通过展示自己作为艺术家的一面来申请假释，梦想获释后“住在德文郡的房车里，用油彩作画。”
