# 监狱摄影  探访法国监狱

![9.43.1](./images/9.43.1.jpg)



![9.43.2](./images/9.43.2.jpg)



![9.43.3](./images/9.43.3.jpg)



![9.43.4](./images/9.43.4.jpg)

2016年11月，马格南摄影师保罗•佩勒格林（Paolo Pellegrin）在法国Meaux Penitentiary待了五天。

![9.43.5](./images/9.43.5.jpg)



![9.43.6](./images/9.43.6.jpg)

法国的监狱同世界其他地方一样，面临着过度拥挤、结构陈旧和囚犯条件恶劣等问题。法国的刑罚体系仅能容纳58681名囚犯，但截至2017年1月1日，法国有78796人被刑事拘留，其中68432人正在服刑。这些数字是欧洲最糟糕的，且经常被欧洲理事会引用。

![9.43.7](./images/9.43.7.jpg)



![9.43.8](./images/9.43.8.jpg)

2015年的恐怖袭击以后，法国宣布进入紧急状态，这意味着一套临时的法律出台，允许扩大监禁政策，以保护国家安全。

![9.43.9](./images/9.43.9.jpg)



![9.43.10](./images/9.43.10.jpg)

2016年11月，佩勒格林拍摄了位于巴黎郊区的Meaux Penitentiary Center，这是一座建于2001年的监狱。这座监狱最初建造容量为332名囚犯，目前关押着550名囚犯。

![9.43.11](./images/9.43.11.jpg)



![9.43.12](./images/9.43.12.jpg)

五天中，佩勒格林表示监狱的透明和工作人员的开放出乎他的意料，他发现囚犯和工作人员也都非常愿意被拍摄，“在任何地方都能遇到“尽可能人性化”的专业精神”。

![9.43.13](./images/9.43.13.jpg)



![9.43.14](./images/9.43.14.jpg)

保罗·佩勒格林1964年出生于意大利罗马。曾在罗马大学学习建筑，之后转行研习摄影。1991年至2001年间，佩勒格林由巴黎的VU图片社代理。在此期间也是美国“新闻周刊”杂志和德国Zeit杂志的签约摄影师。

![9.43.15](./images/9.43.15.jpg)



![9.43.16](./images/9.43.16.jpg)

2001年，获马格南图片社提名，并于2005年成为正式会员。
