# 俄罗斯监狱戏剧

![3.11.1](./images/3.11.1.jpg)



![3.11.2](./images/3.11.2.jpg)

​2009年，英国戏剧导演亚历克斯·道尔（Alex Dower）带领俄罗斯伯姆监狱（Perm Prison Colony 29）的囚犯排演了三部话剧，这三部话剧改编自三个短篇小说：契诃夫的《鳕鱼》（The Burbot）、伊萨克·巴别尔的《我的第一只鹅》和该监狱囚犯阿尔伯特·萨鲁季诺夫的《蝴蝶》。最终，这些作品以录播的方式参加了当年的领土国际当代戏剧节（ Territoria International Contemporary Theatre Festival）。

![3.11.3](./images/3.11.3.jpg)



![3.11.4](./images/3.11.4.jpg)

与亚历克斯一起进入监狱的还有他的两位伙伴，其中塞巴斯蒂安·李斯特（Sebastian James Lister）即是戏剧老师也是一名摄影师，在排戏的过程中，他拍摄了下面这组照片。

![3.11.5](./images/3.11.5.jpg)



![3.11.6](./images/3.11.6.jpg)

第一周，他们需要阅读剧本和分析剧本

![3.11.7](./images/3.11.7.jpg)



![3.11.8](./images/3.11.8.jpg)

亚历克斯在伦敦接受的是俄罗斯演员萨姆·科根的表演体系，如今他们把科根的系统带了回来。

![3.11.9](./images/3.11.9.jpg)



![3.11.10](./images/3.11.10.jpg)

虽然几乎从来没进过剧场，囚犯们非常喜欢这机会，他们得以短暂的从枯燥阴郁的生活中抽离出来，发挥想象力，在戏剧中获得自由的感觉。

![3.11.11](./images/3.11.11.jpg)



![3.11.12](./images/3.11.12.jpg)

一位前新纳粹杀人犯在巴别尔的《我的第一只鹅》中扮演犹太人。

![3.11.13](./images/3.11.13.jpg)



![3.11.14](./images/3.11.14.jpg)

整个项目期间，囚犯们都表现积极。排戏需要团队合作，需要沟通，需要理解角色、理解其他演员、考虑观众。对参与者自我意识的提升、同理心、自尊、自信的培养都有相当的积极作用。

![3.11.15](./images/3.11.15.jpg)



![3.11.16](./images/3.11.16.jpg)

契诃夫的《鳕鱼》的演员之一伊戈尔出狱后获得了一份专业剧院的工作。

![3.11.17](./images/3.11.17.jpg)



![3.11.18](./images/3.11.18.jpg)

通过这次尝试，当局也注意到排戏对犯人矫治的积极作用。之后，他们把戏剧作为常规项目引进监狱系统。如今，大部分俄罗斯监狱都有了自己的剧团，每年，首都莫斯科还会举办监狱戏剧节。
