# 南非画家恩戈贝尼

布莱辛·恩戈贝尼（Blessing Ngobeni）1985年出生于南非。小时候，他的母亲离开了家，他被迫和他的叔叔生活在一起——用恩戈贝尼后来说，叔叔把他当做奴隶，经常拿鞭子抽他。无奈之下，恩戈贝尼离家出走，到处流浪。他的母亲后来找到了他，把他带到她和她的新丈夫在桑尼恩（Tzanen）的家，1995年，10岁的恩戈贝尼再次离家出走——在街头混了五年，直至被捕。

2000年，15岁的恩戈贝尼因参与武装抢劫而被捕。两年后法院才对他做出判决，判处他九年徒刑。最终，恩戈贝尼于2006年获释。

在监狱里，恩戈贝尼接触到了艺术并自学绘画。出狱的时候，他知道他将来要做一名画家。

之后恩戈贝尼辗转走上艺术之路，作品被Tendai画廊代理。但没过多久，他的200多张画在画廊被盗，这让恩戈贝尼备受打击。一年之后，恩戈贝尼重拾画笔，用蒙太奇、绘画和扭曲的人物构建自己的风格，并日益成熟。
