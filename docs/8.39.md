# 罗尼·古德曼

![8.39.1](./images/8.39.1.png)



![8.39.2](./images/8.39.2.jpg)


![8.39.3](./images/8.39.3.jpg)



![8.39.4](./images/8.39.4.png)

罗尼·古德曼（Ronnie Goodman）1960年出生于洛杉矶，在旧金山的海特和菲尔莫尔地区（Fillmore）长大，在他青少年时代，海特区艺术氛围浓厚，嬉皮士和反抗运动如火如荼。古德曼耳濡目染各种汹涌的思潮，从6岁开始绘画。

![8.39.5](./images/8.39.5.jpg)



![8.39.6](./images/8.39.6.jpg)

高中阶段古德曼误入歧途，染上了毒瘾。后来，他因一级入室盗窃被判处10年徒刑，在圣昆廷监狱服刑。

![8.39.7](./images/8.39.7.jpg)



![8.39.8](./images/8.39.8.jpg)

在圣昆廷，古德曼加入一个艺术矫正的项目。画了不少肖像以及贺卡，靠这个手艺为自己换取一些咖啡、香烟和其他小东西。

![8.39.9](./images/8.39.9.jpg)



![8.39.10](./images/8.39.10.jpg)

2010年，罗尼重获自己，但他已无家可归，被迫沦为第五大街的露宿者，这如此境遇并没有阻止他继续自己的两大爱好：艺术和跑步。

![8.39.11](./images/8.39.11.png)



![8.39.12](./images/8.39.12.jpg)

艺术为罗尼赢得了不小的名声。他的作品曾在MoMA展出过，并被纽约现代艺术博物馆收藏。还曾出现在佐治亚艺术博物馆、圣弗朗西斯科文化中心、旧金山公共图书馆、市政厅、和伦敦市长办公室......的展览中。被《纽约书评》和《纽约时报》刊登过。

![8.39.13](./images/8.39.13.jpg)



![8.39.14](./images/8.39.14.jpg)

2014年，罗尼参加了旧金山半程马拉松比赛并拍卖他的一幅画，为Hospitalship House筹集了超过4万美元。（Hospitality House是一家无家可归者服务组织，负责开展社区艺术项目。）2016年，他再次参加了半程马拉松比赛，使红石大厦受益匪浅。

![8.39.15](./images/8.39.15.jpg)



![8.39.16](./images/8.39.16.jpg)

罗尼喜欢爵士乐，音乐是他作品中反复出现的主题。

![8.39.17](./images/8.39.17.jpg)



![8.39.18](./images/8.39.18.jpg)

尽管他在艺术方面小有成就，但古德曼的作品仍然遭到旧金山警察和公共工程部门的扫荡。在2017年的一起此类事件中，警方以故意破坏罪拘留了他，并以非法住宿为由对他开出罚单，当时他试图阻止一名公共工程雇员扣押他的50幅画和他睡觉的帐篷。一次次面对粗暴的执法，让罗尼非常沮丧。

![8.39.19](./images/8.39.19.jpg)



![8.39.20](./images/8.39.20.jpg)

罗尼制作了多幅关于露宿人群的蚀刻版画。

![8.39.21](./images/8.39.21.jpg)



![8.39.22](./images/8.39.22.jpg)

他的儿子，也叫罗尼·古德曼（Ronnie Goodman），也是一名壁画家，2014年9月9日被刺伤后抢救无效过世，年仅20岁。这件事对罗尼打击沉重。

![8.39.23](./images/8.39.23.jpg)



![8.39.24](./images/8.39.24.jpg)

2020年8月7日，古德曼被发现死在旧金山传教区红石大厦（Redstone Building）外的帐篷中。
