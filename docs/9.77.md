# 在马拉维监狱教摄影

![9.77.1](./images/9.77.1.jpg)



![9.77.2](./images/9.77.2.jpg)


![9.77.3](./images/9.77.3.jpg)



![9.77.4](./images/9.77.4.jpg)

马拉维第三大城市姆祖祖（Mzuzu）少年监狱的条件十分恶劣。这座监狱由英国人在20世纪60年代初建造，最初设计容纳50名囚犯。如今，监狱关押着450名囚犯，其中包括60名未成年人。白天，囚犯们可以在院子里活动，但下午3点半之前，他们就会被锁回牢房。

![9.77.5](./images/9.77.5.jpg)



![9.77.6](./images/9.77.6.jpg)

去年，荷兰摄影师卡迪尔·范·洛胡伊岑（Kadir van Lohuizen）与一家名为“狱中青年”（Young in Prison）的非政府组织合作，得以进入这座监狱。该组织致力于为青少年提供重返社会的帮助。他为12名青少年举办了一场摄影工作坊。

![9.77.7](./images/9.77.7.jpg)



![9.77.8](./images/9.77.8.jpg)

“这是一个非常正式的工作坊，上午上课，下午拍摄。”范·洛胡伊岑告诉《时代》杂志。“令人惊讶的是，这几乎成了他们的一种疗愈方式。对很多孩子来说，这是他们第一次在照片中看到自己。”

![9.77.9](./images/9.77.9.jpg)



![9.77.10](./images/9.77.10.jpg)

在为期一周的研习班上，范·洛胡伊岑的学生们最初几天表现得十分强悍，摆出各种阳刚的姿势面对镜头。“但一周后，他们的转变令人瞩目，”他说。“他们开始谈论自己的生活，并由此展开了关于他们最初是如何走到今天这一步的讨论。我觉得这真的产生了影响。”

![9.77.11](./images/9.77.11.jpg)



![9.77.12](./images/9.77.12.jpg)

通过这次研习班，范·洛胡伊岑也获得了前所未有的机会进入监狱。“通常情况下，监狱里有很多限制，所以你只有很短的时间可以工作。”这一次，他可以随心所欲地待下去，与所有囚犯互动，从而创作出更完整的作品，展现监狱里恶劣的生存状况。“这些囚犯中许多人只犯了轻罪，这主要是由于国家的经济和社会问题造成的，”他说。

![9.77.13](./images/9.77.13.jpg)



![9.77.14](./images/9.77.14.jpg)

巴拉卡·姆戈德的父母前往马拉维姆祖祖少年犯监狱探望儿子。他们被禁止互相接触。姆戈德因偷窃手机被判处三年半监禁。
