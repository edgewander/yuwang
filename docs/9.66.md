# 亚历山大·格里亚季洛夫

![9.66.1](./images/9.66.1.webp)



![9.66.2](./images/9.66.2.webp)


![9.66.3](./images/9.66.3.webp)



![9.66.4](./images/9.66.4.webp)

2001年起，乌克兰纪实摄影师亚历山大·格里亚季洛夫（Alexander Glyadyelov）在国际人道主义组织“医生无国界”协调下，深入俄罗斯、吉尔吉斯斯坦、哈萨克斯坦、乌克兰四国的多所监狱，持续数年进行“人与监狱”系列创拍摄。

![9.66.5](./images/9.66.5.webp)



![9.66.6](./images/9.66.6.webp)

格里亚季洛夫也配合无国界医生进行了结核病、艾滋病等主题的拍摄。

![9.66.7](./images/9.66.7.webp)



![9.66.8](./images/9.66.8.webp)

亚历山大·格里亚季洛夫，乌克兰摄影师，1956年生于波兰，80年代自学摄影，曾在欧洲、中亚、非洲和美国工作。获多项摄影奖，出版有三本摄影集。格里亚季洛夫报道了摩尔多瓦、纳戈尔诺-卡拉巴赫、车臣、吉尔吉斯斯坦、索马里、南苏丹和乌克兰的军事冲突，在摩尔多瓦和顿巴斯两次受伤。1997年至今，格里亚季洛夫一直积极与国际人道主义组织“无国界医生”合作，以摄影师的身份参与项目。近两年，格里亚季洛夫也记录了俄乌战争的残酷与伤痛。
