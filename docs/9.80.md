# 保罗·科尔镜头下的萨尔瓦多监狱

![9.80.1](./images/9.80.1.jpg)



![9.80.2](./images/9.80.2.jpg)

保罗·科尔镜头下的萨尔瓦多监狱

![9.80.3](./images/9.80.3.jpg)



![9.80.4](./images/9.80.4.jpg)

萨尔瓦多是美洲监狱过度拥挤程度最高的国家。这导致囚犯遭受非人道待遇。在这个世界上最暴力的国家，监狱里普遍存在营养不良、地方性疾病和狱内犯罪，这些现象每天都在上演。

![9.80.5](./images/9.80.5.jpg)



![9.80.6](./images/9.80.6.jpg)

在该国最大的监狱——中央监狱“拉埃斯佩兰萨”（俗称“马里奥纳”），拥挤程度高达600%。5000名囚犯挤在原本只能容纳800人的空间里。

![9.80.7](./images/9.80.7.jpg)



![9.80.8](./images/9.80.8.jpg)

降临后，囚犯们挤在没有卫生间、很多时候甚至没有自来水的牢房里。这迫使他们只能将粪便扔过牢房的铁栏杆。

![9.80.9](./images/9.80.9.jpg)



![9.80.10](./images/9.80.10.jpg)

西班牙摄影师保罗·科尔（Pau Coll）在萨尔瓦多监狱拍下这一组作品。

![9.80.11](./images/9.80.11.jpg)



![9.80.12](./images/9.80.12.jpg)

保罗·科尔是一位经验丰富的西班牙摄影记者，现居巴塞罗那。曾在尼加拉瓜、危地马拉、墨西哥、古巴、萨尔瓦多、阿尔及利亚、尼泊尔和欧洲等地拍摄过大量摄影报道和纪录片，积累了在不同国家的监狱、难民营和人道主义紧急情况下进行报道的经验。

![9.80.13](./images/9.80.13.jpg)



![9.80.14](./images/9.80.14.jpg)

保罗·科尔曾荣获多项国内和国际摄影奖项，并入围2013年加西亚·马尔克斯新闻调查奖和2014年阿莱克西亚基金会奖学金的最终候选名单。
