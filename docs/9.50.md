# 法国摄影师格利高里·科尔加诺作品

![9.50.1](./images/9.50.1.jpg)



![9.50.2](./images/9.50.2.jpg)



![9.50.3](./images/9.50.3.jpg)



![9.50.4](./images/9.50.4.jpg)

“监狱的形象更多是被人们建构起来的，我所见到的监狱并没有特别之处。真正让日常成为噩梦，把监狱变成地狱的是多重和一再有辱人格的管理方式——无视规则、脏乱差、孤立、前途无望.....”

![9.50.5](./images/9.50.5.jpg)



![9.50.6](./images/9.50.6.jpg)

2011年1月——2014年1月，法国摄影师格利高里·科尔加诺（Grégoire Korganow）走访拍摄了20所法国监狱。

![9.50.7](./images/9.50.7.jpg)



![9.50.8](./images/9.50.8.jpg)

2010年，科尔加诺为监狱主题纪录片《在共和国的阴影下》拍摄剧照。电影拍完后，监狱局官员问科尔加诺是否愿意与监狱局合作，参与完成一份法国监狱的档案。这是一个难得的绝好机会。于是，在接下来的三年里，科尔加诺去了20所法国监狱，在每所监狱拍摄5到10天。

![9.50.9](./images/9.50.9.jpg)



![9.50.10](./images/9.50.10.jpg)

“我深入到了法国监狱的核心，”科尔加诺说。“我可以拍摄牢房、运动场、探视室、浴室、禁闭室……白天或晚上的一切。完全没有禁区。”

![9.50.11](./images/9.50.11.jpg)



![9.50.12](./images/9.50.12.jpg)

双方达成了协议，合作期间科尔加诺将照片提交给官方。在2014年5月后，该项目照片版权归科尔加诺所有。

![9.50.13](./images/9.50.13.jpg)



![9.50.14](./images/9.50.14.jpg)

“这在法国前所未有，”科尔加诺说。“从来没有摄影师在监狱里可以如此自由。”

![9.50.15](./images/9.50.15.jpg)



![9.50.16](./images/9.50.16.jpg)

“我尽量与被拘留者坦诚以待。我花了很多时间倾听，监狱是一个缺乏倾听的地方。我没有判断或问他们做了什么。我始终保持友善，即使当一些囚犯对我不友善的时候。被拘留者之间的暴力很常见，一双梦寐以求的运动鞋、一支烟或一个表情都可能引发斗争。他们沉默寡言，但极其残忍。”

![9.50.17](./images/9.50.17.jpg)



![9.50.18](./images/9.50.18.jpg)

科尔加诺得知，在法国监狱里，每三天就有一个被监禁者企图自杀。

![9.50.19](./images/9.50.19.jpg)



![9.50.20](./images/9.50.20.jpg)

科尔加诺的这组摄影作品由Neus Les Belles Lettres出版，书名为《监狱——67065》，“67065”指的是该摄影集出版时法国监狱系统中的囚犯人数。

![9.50.21](./images/9.50.21.jpg)



![9.50.22](./images/9.50.22.jpg)

格利高里·科尔加诺（Grégoire Korganow）毕业于巴黎爱斯提尔尼高等艺术学校应用艺术专业，23岁开始摄影。1991年的旅行中的他见证了前苏联解体并打下了职业基础。格利高里·科尔加诺关注现实，他的作品意在向人们展现当今现实世界的断层、悖谬和混乱。他关注镜头外最细小的事物。身体、伤痕、社会形态转变是其作品的主要题材。作品包括：“蜗居者”（1994）、“非法移民”（1995）、“智利马普切印第安人”（又名“反抗”，2003）、“伊拉克罹难者”（又名“战争创伤”，2010）、“酗酒者”（2011）等，2012年他在巴黎一大摄影学院任教并定期在阿尔勒国际摄影协会开展工作坊。他的工作领域还涉及电影和广播。
