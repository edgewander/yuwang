# 百年变迁饮马塘

![9.53.1](./images/9.53.1.jpg)



![9.53.2](./images/9.53.2.jpg)

监狱摄影 | 百年变迁饮马塘

![9.53.3](./images/9.53.3.jpg)



![9.53.4](./images/9.53.4.jpg)

饮马塘监狱, 安徽省唯一一所有着百年变迁史的老监狱。

![9.53.5](./images/9.53.5.jpg)



![9.53.6](./images/9.53.6.jpg)

饮马塘监狱源于清代安庆习艺善堂。习艺善堂为收容偷窃等轻罪犯处。清光绪三十二年(1906年)四月, 清廷准于在安徽省省府安庆设罪犯习艺所。安徽布政使司遂将习艺善堂改为习艺所，立"习艺所"石碑一块，至今犹存，镶嵌在原监区大门旁的围墙上。

![9.53.7](./images/9.53.7.jpg)



![9.53.8](./images/9.53.8.jpg)

习艺所由手工业艺人传授生产技艺，先后开办的生产项目有：印刷、织布、缝纫、碾米、刺绣、藤竹、雨伞，木器等科。其产品对外销售，每月"收入约千元，内盈余百元"。1915年、1919年和1923年，曾参加全国京外监狱第一、二、三次出品展览会，并获奖。习艺所内还附设讲习所，"于罪犯习艺之余，教以识字明理，学习算术"。

![9.53.9](./images/9.53.9.jpg)



![9.53.10](./images/9.53.10.jpg)

习艺所于宣统二年(1910年), 改为模范监狱, 省城府司县三狱和习艺所、新羁所各犯全部划入。1916年扩建后，改为安徽省第一监狱，又称安徽省第一模范监狱。1919年，怀宁地方看守所并入，1924年，饮马塘增设安徽省第一监狱分监。1930年，安徽省反省院成立，亦设于饮马塘看守所内。1933年，反省院迁往黄家狮陆军监狱，1938年，安庆沦陷，饮马塘狱所为汪伪所控，名为"怀宁县地方法院看守所"。1945年8月，抗日战争胜利后，饮马塘监狱由国民党安徽省高等法院和怀宁县法院共同接收使用。

![9.53.11](./images/9.53.11.jpg)



![9.53.12](./images/9.53.12.jpg)

中共领导人任弼时、安徽省委第一任书记王步文等, 都曾被国民党当局关押在此。

![9.53.13](./images/9.53.13.jpg)

1949年４月，由新政府接管。饮马塘监狱定名为"皖北安庆行政区监狱"。1952年6月，改为"安庆专员公署公安处直属劳改大队"。1955年6月，由安徽省公安厅正式定名为"安徽省第二监狱"。1994年底, 《监狱法》颁布实施。次年初, 按照司法部统一部署, 更名为"安徽省安庆监狱"，也就是后来的安徽省第一监狱。

![9.53.14](./images/9.53.14.jpg)

2009年9月, 安庆监狱老监区近千名在押犯转移至新监区, 饮马塘监狱空置后曾对外出租，现空置。
