# 瑞典画家艾萨克·格吕内瓦尔德

![8.50.1](./images/8.50.1.webp)



![8.50.2](./images/8.50.2.webp)



![8.50.3](./images/8.50.3.webp)



![8.50.4](./images/8.50.4.webp)

艾萨克·格吕内瓦尔德（Isaac Grünewald，1889年-1946年），瑞典表现主义画家、作家。1889年出生于斯德哥尔摩。从1910年直到1946年去世，格吕内瓦尔德创作了大量的画作，是第一代瑞典现代主义的领军人物。 20世纪20年代，格吕内瓦尔德取得一系列商业上的成功。他为瑞典皇家歌剧院和其他剧院设计舞台。1925年至1926年，他装饰了诺贝尔奖颁奖典礼所在地斯德哥尔摩音乐厅的小厅（后更名为格吕内瓦尔德厅）的墙壁和天花板，并于1928年装饰了Matchstick宫。在1932年的夏季奥运会绘画比赛中他的作品备受关注。

![8.50.5](./images/8.50.5.webp)



![8.50.6](./images/8.50.6.webp)

1923年5月的一个晚上，一群艺术家兴致勃勃的来到布胡斯（Bohus，瑞典西部的一座小城）火车站，他们将由此前往哥德堡，参加即将举办的北欧艺术展。来车站之前，他们在餐厅聚了一把，庆祝画展的开幕。

![8.50.7](./images/8.50.7.webp)



![8.50.8](./images/8.50.8.webp)

大概晚餐没少喝，艺术家们比较兴奋，引起了其他候车乘客的不满，有乘客向工作人员投诉。车站工作人员便过来维持秩序，这时火车来了。这群艺术家中就有格吕内瓦尔德和他的妻子Sigrid Hjertén。眼看火车要开了，工作人员拦住Sigrid Hjertén不放，还发生了肢体冲突。情急之下，格吕内瓦尔德出手打了车站工作人员。

![8.50.9](./images/8.50.9.webp)



![8.50.10](./images/8.50.10.webp)

随之而来的是一场漫长的诉讼。

![8.50.11](./images/8.50.11.webp)



![8.50.12](./images/8.50.12.webp)

三年后，格吕内瓦尔德被判处一个月的监禁并交纳罚款。

![8.50.13](./images/8.50.13.webp)



![8.50.14](./images/8.50.14.webp)

1926年5月，格吕内瓦尔德被送到斯德哥尔摩的Långholmen监狱，登记为693号囚犯，狱警将他带入232号牢房。不过他享有些许特权：不必穿条纹囚服（他带了自己的大红长袍），可以携带自己的绘画用品。于是，在一个月的服刑期内，格吕内瓦尔德创作了近五十幅画作。做卫生锻炼身体自画像1946年，格吕内瓦尔德和第二任妻子Märta Grundell在一次飞机失事中丧生。Långholmen监狱在斯德哥尔摩市内的一个小岛上，该建筑最初是酿酒师Jochum Ahlstedt于17世纪50年代建造的。1724年瑞典政府收购了该建筑，并改建为监狱。服役250年后，Långholmen监狱于1975年关闭。之后改为民用，1989年，Långholmen酒店和青旅开业，提供住宿、餐饮和会议服务。酒店还有一个监狱博物馆，并设计了数个监狱主题的活动供客人参加。
