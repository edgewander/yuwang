# 2025普利策摄影奖获奖作品：叙利亚赛达纳亚监狱


![9.71.1](./images/9.71.1.jpg)


![9.71.2](./images/9.71.2.jpg)

2025年5月6日，第109届普利策奖揭晓。


![9.71.3](./images/9.71.3.jpg)

普利策奖始于1917年，每年评选一次，目前包括15项新闻类奖项、8项创作类奖项和1项特别表彰奖。其中摄影类奖项有两项：突发新闻奖和专题摄影奖。


![9.71.4](./images/9.71.4.jpg)

本届突发新闻奖颁给拍摄川普竞选演讲遇袭瞬间的纽约时报摄影师Doug Mills。


![9.71.5](./images/9.71.5.jpg)

专题摄影奖（Feature Photography）获奖者为马格南摄影师莫伊塞斯·萨曼（Moises Saman），2024年底，莫伊塞斯·萨曼作为纽约客的特约摄影师远赴叙利亚，记录了阿萨德政权倒台后的种种。


![9.71.6](./images/9.71.6.jpg)

获奖作品：


![9.71.7](./images/9.71.7.jpg)

▲1. 赛达纳亚监狱（Sednaya）位于大马士革北部，是全球最臭名昭著的拘押设施之一。据人权组织统计，超过30,000名囚犯在这里遭受酷刑、饥饿甚至大规模处决，被称为“人间屠场”。


![9.71.8](./images/9.71.8.jpg)

▲2. 2024年12月，巴沙尔·阿萨德政权垮台后，一名妈妈领着孩子进入赛达纳亚监狱内寻找失踪的亲人。


![9.71.9](./images/9.71.9.jpg)

▲3. 另人毛骨悚然的监狱


![9.71.10](./images/9.71.10.jpg)

▲4. 一名男子循着尸体的气味，在赛达纳亚监狱的墙体之间搜寻线索。


![9.71.11](./images/9.71.11.jpg)

▲5. 梅泽空军基地（Mezzeh）地下室，囚室狭小无窗，曾关押并酷刑折磨异议人士，如著名活动家马赞·哈马达（Mazen al-Hamada）。


![9.71.12](./images/9.71.12.jpg)

▲6. 巴勒斯坦分局墙上的模糊指纹，是囚犯在登记或身份确认过程中留下的痕迹


![9.71.13](./images/9.71.13.jpg)

▲7. 访客在巴勒斯坦分局看到一批囚犯照片，这些照片可能是在登记或审讯期间拍摄。


![9.71.14](./images/9.71.14.jpg)

▲8. 穆塔森·卡坦（Motasem Kattan）重演自己在巴勒斯坦分局被关押时所经历的苦难，站立的男子的他的父亲。


![9.71.15](./images/9.71.15.jpg)

▲9. 巴勒斯坦分局大楼内的办公室，墙上带有官方印章与密码标记的文件中，记录了酷刑、审讯、逮捕令与监控行为。


![9.71.16](./images/9.71.16.jpg)

▲10. 在Al-Khatib监狱地下室发现的酷刑器具。该监狱由叙利亚情报机关运营，位于大马士革一处基督徒社区中，尽管隐藏极深，但附近居民仍常听见囚犯的尖叫声。


![9.71.17](./images/9.71.17.jpg)

▲11.在达拉郊外的乱葬坑中发现的数十具尸体，被集中存放于伊兹拉（Izra）镇的停尸间。


![9.71.18](./images/9.71.18.jpg)

▲13.找到亲人尸体的年轻人


![9.71.20](./images/9.71.20.jpg)

▲14.马赞·哈马达的葬礼现场，亲属与支持者数百人聚集哀悼，其嫂马吉达·卡多（Majida Kaddo）多年未能见其生前一面，直到在大马士革郊外发现其遗体。

▲15. 大马士革郊外的空坟坑，由阿萨德政权挖掘，其周围有明显被使用过的掩埋坑，显露出隐藏尸体的痕迹。
