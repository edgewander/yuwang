# 不羁的蝴蝶--匈牙利监狱常客费伦茨·迪克

![9.63.1](./images/9.63.1.webp)



![9.63.2](./images/9.63.2.webp)



![9.63.3](./images/9.63.3.webp)



![9.63.4](./images/9.63.4.webp)

不羁的蝴蝶（Unwanted Butterfly），一位匈牙利监狱常客，他40岁的生命中，有20年在监狱里度过。这位浑身刺青的混不吝本名费伦茨·迪克（Ferenc Deák，与匈牙利一位著名政治家同名）。因为额头上刺了一款名为Pillangó的匈牙利蝴蝶，被称为不羁的蝴蝶。

![9.63.5](./images/9.63.5.webp)



![9.63.6](./images/9.63.6.webp)

费伦茨于1954年出生于布达佩斯，不顾家的父亲在他五岁时就离开了他们。费伦茨六岁开始抽烟，四年级就被关进了青少年监狱，15岁，他被法庭定罪。“没什么大不了的，我被判在少管所羁押一年，但是第三天我就跑掉了，他们抓住了我，把我带了回去。”

![9.63.7](./images/9.63.7.webp)



![9.63.8](./images/9.63.8.webp)

成年后的费伦茨更是频繁出入监狱，他的罪名有：欺诈、入室盗窃、越狱、监狱暴乱、暴力侵害执法人员、非法越境、车辆盗窃、故意破坏、夜间强行非法侵入、种族主义、性侵犯和故意伤人...刑期前后近20年。跟让·热内有点像，费伦茨“常住地狱、常乐地狱、庄严地狱”。他在监狱里写诗、设计填字游戏和棋盘游戏、画画。1978年，他开始给自己纹身，浑身上下纹了个遍，第一个作品是额头上的一只匈牙利蝴蝶——“我用了十天的时间来完成它。”

![9.63.9](./images/9.63.9.webp)



![9.63.10](./images/9.63.10.webp)

费伦茨受邀参加匈牙利著名的Friderikusz脱口秀（在一个社区中心录制）

![9.63.11](./images/9.63.11.webp)



![9.63.12](./images/9.63.12.webp)

1988年摄影师Tamás Urbán在匈牙利塞格德的Csilag监狱第一次见到费伦茨。

![9.63.13](./images/9.63.13.webp)



![9.63.14](./images/9.63.14.webp)

Tamás Urbán和费伦茨

![9.63.15](./images/9.63.15.webp)



![9.63.16](./images/9.63.16.webp)

费伦茨是地下黑洞俱乐部的常客，在那里他将与当时流行的地下乐队Sziámi同台演出。

![9.63.17](./images/9.63.17.webp)



![9.63.18](./images/9.63.18.webp)

1994年，40岁的费伦茨试图游到多瑙河的小岛屿内普齐盖，再游回来。他做到了，但几天后他的身体才出现在链桥脚下。

![9.63.19](./images/9.63.19.webp)



![9.63.20](./images/9.63.20.webp)

Tamás Urbán为费伦茨制作了摄影集并举办了摄影展。
