## 关于狱望

《狱望》从「艺术介入监狱」入手，收集整理各种监狱与艺术相关的案例和资料。涵盖文学、音乐、绘画、摄影、戏剧、瑜伽冥想等多种形式，探讨艺术、自由、人性、矫正与救赎。

我们正在推动**监狱主题旅游**成为一个被认可的旅行品类。《世界监狱博物馆巡礼》收录全球282座合法的监狱主题目的地，配合地图，按图索骥，全世界打卡。
