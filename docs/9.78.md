# 布隆迪监狱中的少年

![9.78.1](./images/9.78.1.jpg)



![9.78.2](./images/9.78.2.jpg)

布隆迪监狱中的少年

![9.78.3](./images/9.78.3.jpg)



![9.78.4](./images/9.78.4.jpg)

2009年，德裔伊朗摄影师娜塔莉·莫哈杰（Nathalie Mohadjer）国际正义桥梁组织（IBJ）的摄影师进入布隆迪工作，两个月后，她和另两个NGO组织合作（人权保护协会（APRODH）和布隆迪囚犯权利捍卫协会 (ABDP)），拍摄了布隆迪触目惊心的司法现状。

![9.78.5](./images/9.78.5.jpg)



![9.78.6](./images/9.78.6.jpg)

布隆迪各地都有拘留所——几乎每个小村庄都有。此外，还有一些非法拘留所。当警察不知道该如何处置这些人时，他们就被扔进那里。

![9.78.7](./images/9.78.7.jpg)



![9.78.8](./images/9.78.8.jpg)

人权保护协会做了很多工作，他们知道这些拘留所的位置。他们会突击探访这些拘留所，发现有被无端关押的人，会要求立即释放，他们的确能做到。

![9.78.9](./images/9.78.9.jpg)



![9.78.10](./images/9.78.10.jpg)

娜塔莉·莫哈杰随着人权组织拍摄了一组名为“地牢”（The Dungeon）的摄影作品，“我努力寻找合适的词，“地牢”你会想到历史、黑暗的墙壁和洞穴，它隐蔽，没有光线。这就是我看到那些拘留所的感觉。在某个村庄的中心，人们带你从房屋后面绕过去，打开紧缩的门，房间里挤满了人，都望着你。墙壁是红色和黑色的，上面刻满了人名。你感觉自己正在目睹一个地狱。”

![9.78.11](./images/9.78.11.jpg)



![9.78.12](./images/9.78.12.jpg)

布隆迪没有完善的法律体系，漏洞百出，不知道该如何安置这些人。

![9.78.13](./images/9.78.13.jpg)



![9.78.14](./images/9.78.14.jpg)

布隆迪宪法规定最高审前羁押期为十四天，现实是他们常常要等一年，甚至两年才能见到法官。

![9.78.15](./images/9.78.15.jpg)



![9.78.16](./images/9.78.16.jpg)

有的拘留所是男女混合关押的。

![9.78.17](./images/9.78.17.jpg)



![9.78.18](./images/9.78.18.jpg)

对许多囚犯来说，他们所遭遇的唯一罪行就是被监禁，以及遭受警察的酷刑。他们因各种各样的罪名被捕，从巫术到谋杀，不一而足——或者像西比托克10岁的埃利-戴维德那样，仅仅因为目睹陌生人偷DVD就被捕——这些不幸的人从警察的暴力手中落入狱长的魔爪，遭受虐待：“如果有人交不起‘卡乔特税’，他一周不许坐下，不许吃饭——他必须睡在我们晚上拉屎的角落里。”

![9.78.19](./images/9.78.19.jpg)



![9.78.20](./images/9.78.20.jpg)

孩子们在黑暗的牢房里饱受煎熬。他们是所谓任意司法的受害者，多年来从未踏入过法庭。
